# Screenshot assets

Images referenced from pull requests and issues opened against `l0ng-ai/openidea`.
Nothing on this branch is part of the app; it only exists so the links stay valid.

- **Never delete this branch.** Every embedded image points at `raw.githubusercontent.com` on it.
- Layout: `screenshots/<topic>/<name>.png`, where `<topic>` is a short slug for the PR or
  branch (for example `terminal-exit-close`). Reuse the same topic folder for follow-up
  screenshots.
- Keep the originals at 2x device pixel ratio and leave the surrounding UI in frame.
- Reference an image with:

  ```
  https://raw.githubusercontent.com/zhzhsx/openidea/assets/screenshots/<topic>/<name>.png
  ```
